# Genesis Grand Prix

A Formula 1-themed hackathon website developed for Genesis Grand Prix, organised by the Node Club at BMSIT.

## Features
- Interactive 3D Red Bull RB16B model
- Multiple camera views and model controls
- Full-screen F1 flag intro animation
- Responsive interface

## Tech Stack
- HTML
- CSS
- JavaScript
- Three.js

## Run Locally

```bash
git clone https://github.com/Ojasva-Tiwari/genesis-grand-prix.git
cd genesis-grand-prix
python -m http.server 5500
```

Open `http://localhost:5500` in your browser.
